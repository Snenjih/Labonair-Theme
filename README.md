# Labonair Theme

A clean and focused theme for the [Zed](https://zed.dev) editor, available in four variants across dark and light appearances with gold and purple accent options.

## Variants

| Variant | Appearance | Accent |
|---|---|---|
| Labonair Dark | Dark | Gold `#E6B450` |
| Labonair Dark Purple | Dark | Purple `#9046FE` |
| Labonair Light | Light | Gold `#E6B450` |
| Labonair Light Purple | Light | Purple `#9046FE` |

## Installation

### Via the Zed Extension Panel

1. Open Zed and go to **Extensions** (`zed: extensions` from the command palette, or `Cmd+Shift+X`).
2. Search for **Labonair**.
3. Click **Install**.
4. Open the theme picker (`zed: open theme selector`) and select your preferred variant.

### Via `extensions.toml`

Add the following to your project or global `extensions.toml`:

```toml
[extensions]
labonair-theme = "0.1.0"
```
